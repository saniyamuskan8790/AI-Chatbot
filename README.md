# AI Chatbot (Python)

## Overview

This project is a simple AI Chatbot built using Python. It interacts with users by accepting text-based input and providing predefined responses. The project is designed to demonstrate the basics of chatbot development and Python programming.

## Features

* Interactive text-based conversation
* User-friendly command-line interface
* Responds to predefined user inputs
* Simple and easy-to-understand Python code

## Technologies Used

* Python

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the Python file:

   ```bash
   python chatbot.py
   ```
4. Start chatting with the chatbot.

* Python programming fundamentals

* Functions
* User input and output handling
* Basic chatbot logic
